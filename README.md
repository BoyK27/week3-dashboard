# week3-dashboard
A weather dashboard for assignment week 3 showing the use of API na dasync functions fectch.
To run the project you simple load the html file in your browser either through live server or open it
using any browser of your choice which will in turn load the Javascript and the render it to your browser.

The API used in this mini project is the open Meteor weather API to capture the temperature lon and lats
of variosu cities and laces around the globe with their current weather conditions.
